# 舰长失能

- 稳定规则 ID：`IBS-R-CAPTAIN-01`
- 来源边界：这是对局制作方指定的在线兵棋操作规则，不声称为原始规则书的逐字规则。若某想定特例另有规定，想定特例优先。

## 操作

舰长在第 N 回合被判定负伤或阵亡时，其舰从第 N+1 回合起失去玩家指挥一个完整回合。该回合舰只自动保持上一回合速度直航，不执行玩家下达的移动、炮击、鱼雷、照明弹、探照灯、烟幕或其他行动。回合结束后，舰长状态仍保留；玩家从下一回合恢复指挥，除非另有规则或裁判状态覆盖。

裁判直接将舰长状态改为负伤或阵亡时，同样从当前回合之后的下一回合触发。裁判将其改回正常时，清除尚未生效的失能计划。

## 引擎约束

- `ShipState.captain_command_loss_turn` 记录唯一的失能回合。
- `captain_command_lost` 为该回合的唯一判定入口。
- 引擎移动结算生成自动直航，玩家订单校验拒绝失能舰的其他行动。
- 事件 `captain_incapacitated` 与 `captain_autopilot` 均引用本规则 ID，便于裁判审计。

## 明确范围

此规则只约束舰长负伤或阵亡触发的下一回合，不额外延长到之后的回合。沉没、未部署和被其他舰船/损伤规则强制控制的处理仍按各自规则结算。
