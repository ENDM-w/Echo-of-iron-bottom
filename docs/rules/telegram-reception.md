# 电报接收与受击惩罚

- 稳定规则 ID：`IBS-R-COMMS-01`
- 来源边界：本条是对局制作方指定的平台通信规则，不声称为原始规则书条文。

每则电报在发送后的下一回合，向每个同阵营其他席位分别进行接收判定。通常掷 D100；“风暴降临”时掷 D50。统计收件席位所控制舰船在电报发送回合内的逐次命中结果：炮击命中、鱼雷命中和碰撞结果各计一次。每次命中使该席位本次接收骰值减 8，修正后骰值最低为 1。去除消息中的空白后，字符数严格小于修正后骰值才送达。

原骰、受击次数、修正后骰值、骰面数、字数和送达结果逐接收席位保存，作为裁判审计轨迹。玩家只读取自己席位的电报正文和判定结果，不读取其他接收席位数据。
