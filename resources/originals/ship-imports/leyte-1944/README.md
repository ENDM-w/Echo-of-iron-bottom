# 莱特湾船表来源（2026-10-19）

- `source-images/ship-table-1.png` 至 `ship-table-3.png`：用户提供的三张莱特湾舰船表原图。OCR 仅用于名称/数字检索；已按 `agent.md` 要求回看图像核对表格和炮位。
- `美军算子.rar`：用户提供的美国算子压缩包；`operator-art/us/` 保存从该压缩包提取的单舰 PNG。
- 导入包会引用美国算子。日本算子尚未收到，因此当前计划将相关 `artwork` 留空，之后可用新算子重建本机导入数据。

用户确认的转录规则：名称左侧黑底 A–I 为排水量等级；每个主/副炮图标数字独立建为炮位，箭头决定射界；M 表示火控、R 表示雷达、其上方水机图标表示舰载水上飞机；船首在图左、上方为左舷。圆圈内横杠数表示装载鱼雷数。日本 24 英寸雷映射 Type 93；美国 21 英寸雷先沿用项目 Mk 15-1942 性能；不记录备用雷。已存在其他版本的舰艇使用 `-1944` 名称/ID。

日本算子尚未收到，因此日本记录的导入包 `artwork` 字段应保持空值。舰船数值、炮位/射界须在结构化导入包及逐舰复核表完成后才能导入；OCR 只用于检索，不据其猜测图像中无法确认的字段。
